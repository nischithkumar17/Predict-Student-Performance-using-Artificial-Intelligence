# AI Student Performance Predictor

## Overview
A machine learning web application that predicts student performance and provides AI-powered study recommendations.

## Features
- Student performance prediction
- AI recommendations using Groq
- Prediction history
- CSV export
- PDF report
- Analytics dashboard

## Tech Stack
- Python
- FastAPI
- Scikit-learn
- HTML
- CSS
- JavaScript
- Groq API

## Installation
1. Clone the repository
2. Install requirements
3. Run FastAPI
4. Open the frontend
